# Pir2pir

Pir2pir "Школа 21" ishtirokchilariga o'quv loyihalarini o'zaro tekshirish uchun bir-birini topishda
yordam beradi.

- Telegram-bot: [@pir2pirbot](https://t.me/pir2pirbot)
- Shaxsiy ma'lumotlar bo'yicha murojaatlar: legal@pir2pir.ru

## Bu qanday ishlaydi

1. Botni oching va Школа 21 loginingizni kiriting.
2. Talabalik pochtangizga kelgan kod bilan hisobga egalikni tasdiqlang.
3. Ishtirokchini login bo'yicha toping — botda yoki istalgan chatda `@pir2pirbot login` orqali.
