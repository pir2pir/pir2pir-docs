# Pir2Pir

Pir2Pir помогает участникам Школы 21 находить друг друга для взаимных проверок учебных проектов.

- Telegram-бот: [@pir2pirbot](https://t.me/pir2pirbot)
- Обращения по персональным данным: legal@pir2pir.ru

## Как это работает

1. Откройте бота и укажите логин Школы 21.
2. Подтвердите владение учётной записью кодом со студенческой почты.
3. Найдите участника по логину — в боте или в любом чате через `@pir2pirbot логин`.

Pir2Pir — независимый проект участника сообщества. Сервис не является Школой 21, не аффилирован с ней
и не действует от её имени.
