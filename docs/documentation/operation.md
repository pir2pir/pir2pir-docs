## Запуск, работа и завершение

| Действие | Порядок |
| --- | --- |
| Запуск | открыть в браузере адрес https://app.pir2pir.ru и войти в учётную запись |
| Полноценная работа | доступны все функции, перечисленные в [Функциональных характеристиках](./functional.md) |
| Завершение | выйти из учётной записи в разделе профиля либо закрыть вкладку браузера; несохранённых данных не остаётся — сообщения и запросы сохраняются на сервере в момент отправки |

Отдельного запуска и остановки серверной части пользователем не производится: программное
обеспечение работает непрерывно на инфраструктуре правообладателя.

## Порядок работы

### Поиск проверяющего

1. Открыть раздел поиска.
2. Выбрать учебный проект из списка проектов, которые участник уже начал или на которые записался.
3. Подтвердить начало поиска. До подтверждения отображается число потенциальных проверяющих.
4. Дождаться отклика: запросы направляются кандидатам последовательно. Поиск продолжается в фоновом
   режиме, приложение можно закрыть.
5. При получении отклика открывается чат.

Поиск можно прекратить в любой момент. Если подходящих участников нет, поиск остаётся активным:
подходящий участник может появиться позже.

### Ответ на запрос о проверке

При поступлении запроса участнику сообщаются учебный проект и кампус — без указания того, кто ищет.
Личность раскрывается только после согласия. Запрос принимается или отклоняется; при отсутствии
ответа он передаётся следующему кандидату.

### Общение

Чат открывается после взаимного согласия. Доступны текстовые сообщения с форматированием и вложения.
Переписка завершается по решению любого из участников либо по истечении срока неактивности; после
завершения её содержимое удаляется в срок, указанный в
[Политике конфиденциальности](../legal/privacy_policy.md).

### Обращение к участнику напрямую

Если известен точный логин, запрос на общение направляется без поиска. Если указанный участник в
сервисе не зарегистрирован, доступно направление одного приглашения с учётом ограничений,
приведённых в разделе «Приглашение обучающегося, не зарегистрированного в сервисе»
[Функциональных характеристик](./functional.md).

### Настройки

В настройках участник управляет получением запросов о проверке и отображением своих данных в
рейтинге. Учётная запись удаляется самим участником; удаление влечёт прекращение обработки данных.

## Поддержка и сопровождение

| Вопрос | Адрес |
| --- | --- |
| Техническая поддержка, ошибки, предложения | support@pir2pir.ru |
| Обращения по персональным данным | legal@pir2pir.ru |

Срок рассмотрения обращения — не более 30 дней с момента получения.

Сопровождение включает устранение ошибок, обновление программного обеспечения и поддержание его
работоспособности. Обновления устанавливаются правообладателем на своей инфраструктуре и не требуют
действий со стороны пользователя.
