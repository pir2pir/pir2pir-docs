## Системные требования

Установка программного обеспечения на устройство пользователя не требуется. Для работы необходимы:

| Параметр | Значение |
| --- | --- |
| Устройство | персональный компьютер, планшет или смартфон |
| Браузер | современный браузер с поддержкой ECMAScript 2022 и Server-Sent Events: Яндекс Браузер (актуальная версия), Google Chrome 94+, Mozilla Firefox 93+, Safari 15.4+, Microsoft Edge 94+ |
| Разрешение экрана | от 320 пикселей по ширине |
| Соединение | доступ в сеть «Интернет», от 1 Мбит/с |
| Дополнительное ПО | не требуется |

Действующая учётная запись обучающегося образовательной организации и доступ к студенческому адресу
электронной почты необходимы для регистрации.

---

## Получение доступа

Программное обеспечение предоставляется по модели SaaS и размещается на инфраструктуре
правообладателя на территории Российской Федерации. Отдельная установка, распаковка дистрибутива или
настройка на стороне пользователя не выполняются.

Порядок получения доступа:

1. Открыть в браузере адрес **https://app.pir2pir.ru**
2. Указать логин учётной записи образовательной организации.
3. Получить одноразовый код на студенческий адрес электронной почты и ввести его в приложении.
4. После подтверждения учётная запись создаётся автоматически, доступ предоставляется немедленно.

Повторный вход выполняется тем же способом. Срок действия одноразового кода — 10 минут.

## Условия функционирования серверной части

Сведения приводятся для полноты описания. Развёртывание выполняется правообладателем; от
пользователя не требуется.

| Компонент | Назначение |
| --- | --- |
| Сервер приложений | платформа .NET, контейнеризованное развёртывание |
| СУБД | PostgreSQL |
| Брокер сообщений | Apache Kafka |
| Обратный прокси | nginx, TLS |

Требования к серверу: операционная система семейства Linux, среда контейнеризации, не менее 4 ГБ
оперативной памяти и 20 ГБ дискового пространства для базового развёртывания. Работа не требует
иностранных программных продуктов и облачных сервисов; используемые сторонние компоненты
распространяются по свободным лицензиям.
